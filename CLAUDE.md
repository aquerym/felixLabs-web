# Рабочая среда — Felix Labs

## Кто пользователь

Продуктовый дизайнер, UI/UX для стартапов. Сейчас в основном ведёт один проект — Felix Labs.

## Проекты

- **Felix Labs** — артефакты в `projects/Felix Labs/`: `Logo/`, `Screens/`, `Design Assets/`, `Social Media stuff/`.
  Дизайн-система и все макеты — в Figma:
  https://www.figma.com/design/DDzJTi7cM2rBaH9K6jIr5c/Felix-Labs
  Также референсы npm-библиотек (React/TS, визуальные эффекты) — исходники для просмотра/переиспользования, когда появится codebase (`npm install <pkg>` туда, а не сюда). Живого кода приложения в среде пока нет:
  - `thinking-orbs/` — canvas-анимация "orb" для AI-интерфейсов, из https://github.com/Jakubantalik/thinking-orbs
  - `Libraries/` — монорепо того же автора: `packages/border-beam` (анимированная обводка), `packages/liquid-gooey` (liquid-эффекты), `packages/thinking-orbs` (дубль стендэлона выше — оставлен намеренно, не синхронизируется), из https://github.com/Jakubantalik/Libraries

Новый проект — новая папка в `projects/<Название>/` с таким же названием, как в чате.

## Дизайн-система

Живёт в Figma (файл Felix-Labs, ссылка выше) — не дублируется локально. Цвета, типографика, компоненты берутся оттуда — не хардкодятся вручную.

## Файлы и результат

- Артефакты — только в `projects/<name>/`, не в корне среды.
- Черновики и то, что не жалко потерять — в `.tmp/`.
- Имя файла — по-английски, коротко, без пробелов там, где повторно используется в коде/экспорте (Figma-экспорты пришли как есть — не переименовывать задним числом).

## Чего нельзя

- Нельзя менять/удалять файлы других проектов.
- Нельзя необратимое (удаление, публикация) без подтверждения пользователя.
- Нельзя хардкодить значения дизайн-системы (цвета, отступы, шрифты) — брать из Figma-токенов/компонентов.
