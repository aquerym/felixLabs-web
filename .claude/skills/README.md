# Скиллы

Здесь живут скиллы — папки с `SKILL.md` под конкретную повторяющуюся задачу, которые подтягиваются по мере надобности (progressive disclosure).

## Установленные

- **transitions-dev** — готовые CSS-переходы (модалки, дропдауны, карточки, тултипы и т.д.), вызывается на "добавь переход", "анимируй dropdown" и т.п. Источник: https://github.com/Jakubantalik/transitions.dev
- **transitions-polish** — ревью/доводка уже применённых переходов (`transitions refine`).
- **better-interface** — координатор кросс-дисциплинарного ревью интерфейса (созывает остальные better-* скиллы).
- **interface-review** — ревью кода интерфейса по запросу пользователя.
- **better-ui** — детали дизайн-инжиниринга (борды, тени, анимации).
- **better-typography** — подбор шрифтов и типографических отступов.
- **better-colors** — цветовые системы и темизация.
- **better-accessibility** — WCAG-соответствие, поддержка клавиатуры.
- **better-layout** — структура и адаптивная вёрстка.
- **better-writing** — UX-копирайтинг и микротексты.
  Источник (8 скиллов выше, кроме transitions-*): https://github.com/jakubkrehel/skills
- **emil-design-eng** — основной скилл: советы по анимации и дизайну (Emil Kowalski).
- **animate** — создание анимаций с правильными кривыми/длительностью/свойствами.
- **review-animations** — аудит анимаций по строгим правилам.
- **improve-animations** — приоритизированный план улучшения существующих анимаций.
- **find-animation-opportunities** — поиск мест в UI, где уместна анимация.
- **animation-vocabulary** — точный словарь для описания анимаций агенту.
- **apple-design** — принципы интерфейса и моушна Apple для веба.
- **pick-ui-library** — выбор UI-библиотеки по проверенным критериям.
- **prototype** — генерация нескольких вариантов UI со сравнением.
- **ask-sonner** — документация по библиотеке тостов Sonner.
  Источник (10 скиллов выше): https://github.com/emilkowalski/skills

Все поставлены `npx skills add <repo>` по прямому запросу пользователя (transitions.dev, jakubkrehel/skills, emilkowalski/skills — все 2026-08-18) — не по правилу "заводить скилл только под задачу, которая реально повторилась" (см. [PRINCIPLES.md](../../PRINCIPLES.md)), это осознанное исключение. Исходники — в `.agents/skills/`, здесь симлинки на них плюс `skills-lock.json` в корне среды.

Новые скиллы под задачи, которые реально начнут повторяться, добавляются сюда так же — по одному, под конкретную задачу.
